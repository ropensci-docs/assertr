# Printing assertr's assert errors

\`print\` method for class "assertr_assert_error" This prints the error
message and the entire two-column \`data.frame\` holding the indexes and
values of the offending data.

## Usage

``` r
# S3 method for class 'assertr_assert_error'
print(x, ...)
```

## Arguments

- x:

  An assertr_assert_error object

- ...:

  Further arguments passed to or from other methods
